# CET Counselor Hub

Build a CET Counsellor web app — an AI agent that helps Maharashtra engineering students with MHT-CET and JEE admissions. The app should have a clean chat interface where students can ask questions about CAP rounds, college cutoffs, and admission procedures for all seat categories including OPEN, OBC, SC, ST, VJNT, EWS, TFWS, PWD, Defense, and Ex-servicemen. Use Sanity as the backend CMS to store structured content like college data, category-wise cutoff scores, and CAP round information. The frontend should be built with Next.js and have a modern, student-friendly design.
